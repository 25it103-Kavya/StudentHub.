# StudentHub Portal

## Theme Colors

Main color: #0FA4AF

Light color: #AFDDE5

Table border color: #0B6E75

## How to run

1. Open the StudentHubPortal folder in VS Code.
2. Make sure the `js` folder exists.
3. Make sure `script.js` is inside the `js` folder.
4. Open `index.html` in a browser.
5. You can also use the Live Server extension in VS Code.

This is a front-end project. The forms currently display JavaScript alerts. A backend and database are required for real login, registration and data storage.
